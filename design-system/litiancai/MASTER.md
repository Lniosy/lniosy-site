# 李天才个人站 · 设计规格

核对日期：2026-11-08。这是本站自己的规格，不是 Apple 官网，也不是技能检索命中。署名见 `design-system/NOTICE.md`。

## 信息架构

1. 身份：李天才 / 天才毛球 / @Lniosytest，中文为主，X 是主页引流。
2. 教程优先：站内教程和 X 长文。
3. 分类推广：美卡与银行、证券、加密 U 卡、出海工具。推广和教程分成两套入口。
4. 单卡页 `/referrals/<slug>/` 与列表共用数据。跳转页 `/go/<id>/` 只负责打开邀请或官网地址。

BIT 证券和 Bybit 是两张卡。StarryBlu 保持 `hidden`。ronvip 保持注释。免费领保持空列表（腾讯打车不恢复）。

## 语义色

| Token | 值 | 用途 |
| --- | --- | --- |
| paper | `#f6f5f3` | 页面底 |
| surface | `#ffffff` | 卡片 |
| ink | `#1c1c1e` | 正文、主按钮底 |
| muted | `#3f3f46` | 次要文字，压在 surface 上需达到正文对比 |
| line | `#1c1c1e1f` | 分隔 |
| accent | `#1f6b45` | 少量强调，不用来单独传意 |
| rebate | `#e4f5a4` | 「我有返利」底，上面仍用 ink 字 |

不提供暗色模式。不使用液态玻璃铺满内容。

## 字阶与间距

- 字体：`system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。不下载 SF。
- 正文 16px，行高 1.6。标题用 600–700，正文 400，不使用细体。
- 说明文字不小于 12px。
- 间距按 8 的倍数。卡片内边距 20–24px。
- 圆角 16px。阴影只用一层很轻的抬起。
- 桌面内容最大宽度 72rem。

## 断点与交互

- 320 / 390 单列，768 开始两列，1024 以上教程网格再拉开，1440 仍限制在最大宽度内。
- 可点目标至少 44px，相邻间距至少 8px。
- 主操作每张卡只有一个（官网或邀请）。教程或推文是次按钮。
- 动效 160–200ms，只用 transform 和 opacity。`prefers-reduced-motion: reduce` 时取消位移动效。
- 键盘焦点 3px 实线，页头粘性时用 `scroll-padding-top`，避免焦点被挡住。
- 每页有「跳到主要内容」。

## 推广卡结构

卡片图、标题、说明、邀请链接或邀请码（可复制）、披露、一个主按钮、可选的文章按钮。这些链接互不嵌套。
