# 李天才个人站 · 设计规格

视觉方向：风格 B · 活力 Bento 名片风（Vibrant Bento）。核对日期：2026-11-24。这是本站自己的规格。署名见 `design-system/NOTICE.md`。

## 信息架构

1. 身份：李天才 / 天才毛球 / @Lniosytest，中文为主，X 是主页引流。
2. 教程优先：站内教程和 X 长文。首页同时是名片，并导流到 X、教程和邀请页。
3. 分类推广：信用卡与银行账户、证券、加密 U 卡、出海工具。推广和教程分成两套入口。信用卡与银行账户这一组的 id 仍是 `bank`，锚点仍是 `#ref-bank`。另外三组锚点是 `#ref-securities`、`#ref-crypto`、`#ref-tools`。
4. 单卡页 `/referrals/<slug>/` 与列表共用数据。跳转页 `/go/<id>/` 只负责打开邀请或官网地址，并保留 Vercel Analytics。

BIT 证券和 Bybit 是两张卡。招商银行全币种 Visa 在 `bank` 组，卡面用官网图。StarryBlu 保持 `hidden`。ronvip 保持注释。免费领保持空列表（腾讯打车不恢复）。

## X 关注者

全站只显示静态标注 `10K+`，日期写 `2026-11-24 更新`。这不是实时人数。文案、首页 Bento、meta / JSON-LD、`llms.txt` 都用 `lib/content.ts` 里的 `X_FOLLOWERS_LABEL` 与 `X_FOLLOWERS_AS_OF`。不要写回旧的精确个位数。

## 字阶与间距

- 字体：系统中文栈。不下载 SF，也不为了试妆去拉外部字体。
- 正文 16px，行高 1.6。标题 800–900，正文 400。不使用细体。
- 说明文字不小于 12px。
- 间距按 8 的倍数。卡片内边距 20–28px。
- 圆角：卡片 24px，名片与关注者卡 28px，主按钮与复制条用全圆药丸。
- 阴影只用一层很轻的落点：`0 5px 0 #bdb0df25`。
- 桌面内容最大宽度 75rem。

## 壳层

- 顶栏：天才毛球头像 + `李天才 / TianCai`，导航「邀请推荐」「精选教程」，深靛药丸 `在 X 关注我 ↗`。
- 手机端主导航和主按钮保持 44px 以上，允许折成两行，不横向溢出。
- 页脚一行身份，链到邀请、教程和 X。
- 每页有「跳到主要内容」。页头粘性，`scroll-padding-top` 避开焦点被挡住。

## 断点与交互

- 320 / 390 单列，768 开始两列，1280 以上邀请卡三列，内容仍限制在最大宽度内。
- 可点目标至少 44px，相邻间距至少 8px。
- 主操作每张卡只有一个（官网或邀请）。教程是次链接。
- 动效 160–200ms，只用颜色和透明度。`prefers-reduced-motion: reduce` 时取消过渡。
- 键盘焦点 3px 实线，偏移 3px。

## 复制条

邀请链接和邀请码用同一条紧凑药丸，高度固定 48px。

- 展示文本单行，超出用省略号。DOM 里仍是完整原文。
- 右侧独立药丸按钮，高度 44px。链接写「复制完整链接」，邀请码写「复制邀请码」。
- 点击后把原始字符串原样写入剪贴板，包含 `#` 路由、空参数和全部追踪字段。不 trim，不改写。
- 成功后按钮改为「已复制」，并用 `aria-live` 读出来。

## 推广卡结构

统一 Bento：定高卡面舞台、分类、标题、一行到两行说明、披露徽章、复制条、一个主按钮、边界脚注。有图用真实卡面（`cmb-visa.png`、Capital One、Wise），无图用品牌字标。这些链接互不嵌套。

单卡详情页：面包屑、桌面两栏 / 手机单栏、舞台、要点、主按钮、48px 复制条，底部单独一张边界声明卡。

「我有返利」只出现在本人的邀请上。Capital One 保持 `notMine`，徽章写「网友分享 · 非本人」。
