# 设计参考署名

本目录由本站根据已阅读的社区技能写成，不是检索脚本的输出。

- 技能：UI UX Pro Max
- 仓库：https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- 固定 commit：`4f2dbb67e64969a9a30ab00742f2d55d66ddec2b`
- 维护者署名：Next Level Builder
- 性质：MIT 社区项目，不是 Apple 官方，也不代表 Apple 背书
- 本站未运行该技能的 `search.py`，因此这里的规格不能称为数据库命中

采用的是技能优先级表和 quick-reference 里适用于网页的规则（无障碍、触控、性能、风格一致、响应式、字阶、克制动效、表单反馈、导航），以及 `styles.csv` 中 `Apple Native Experience` 对响应式网页的描述：内容优先、系统字体、语义色、8pt 间距、克制边框与阴影、150–300ms 过渡、尊重减弱动效。`Liquid Glass` 不用于正文和卡片。

Apple Human Interface Guidelines 的 Layout / Typography 只作原则参考（先重要内容、对齐分组、渐进披露、少字重、避免细字）。原文未收入本仓库，也不使用 SF 字体、SF Symbols 或 Apple 商标。
